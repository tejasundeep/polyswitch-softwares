## 🚀 Installation Guide

### Windows
1. Download [`Polyswitch-1.0.0-setup.exe`](https://github.com/tejasundeep/polyswitch-softwares/releases/download/v1.0.0/Polyswitch-1.0.0-setup.exe).
2. Double-click the installer to launch setup.
3. Once installation completes, Polyswitch will launch automatically and add a shortcut to your Start Menu and Desktop.

### macOS
1. `Polyswitch-1.0.0.dmg` *(Coming Soon)*.
2. Open the `.dmg` file and drag **Polyswitch** into your **Applications** folder.
3. *First Launch Note*: If macOS displays an unidentified developer warning, right-click (or Control-click) the Polyswitch app icon in Applications and select **Open**.

### Linux (Ubuntu / Debian)
1. Download [`Polyswitch-1.0.0-amd64.deb`](https://github.com/tejasundeep/polyswitch-softwares/releases/download/v1.0.0/Polyswitch-1.0.0-amd64.deb).
2. Install via terminal:
   ```bash
   sudo dpkg -i Polyswitch-1.0.0-amd64.deb
   sudo apt-get install -f   # Resolves any missing dependencies
   ```
3. Launch Polyswitch from your application menu or by running `polyswitch` in terminal.

## ⚙️ System Requirements

* **Windows**: Windows 10 or Windows 11 (64-bit)
* **macOS**: macOS 12.0 (Monterey) or later
* **Linux**: Ubuntu 22.04+ / Debian 11+ or compatible desktop distribution
* **Memory**: 4 GB RAM minimum (8 GB recommended)
* **Storage**: ~300 MB free disk space
